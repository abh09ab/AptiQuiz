## 📌 Module Overview
Module 4 expands the portfolio into a professional showcase by integrating a styled Projects section, an Education timeline, and an interactive Resume view & download engine.

### Key Implementations:
1. **Styled Project Cards Grid:**
   - Multi-column project card architecture displaying real-world full-stack applications:
     - **Aptitude Arena 3D (AptiQuiz):** Real-time multiplayer aptitude platform with Three.js graphics, Socket.IO WebSockets, and Google Gemini AI question synthesis.
     - **AI Code Reviewer & Explainer:** Developer productivity tool with algorithmic analysis.
     - **InsightX Analytics Portal:** SaaS dashboard with responsive KPI metrics.
   - Project cards feature technology badges, GitHub source repository links, and live demo buttons.
2. **Academic Education Timeline:**
   - Styled vertical timeline linking academic milestones:
     - **Bachelor of Technology (B.Tech) in CSE (2022 - 2026)** with coursework details.
     - **Higher Secondary Certificate (12th Grade)** with science/math distinction.
3. **Interactive Resume Modal & Download:**
   - Dual trigger buttons ("Resume" in navbar and "Download Resume" in hero section).
   - Modal preview of Curriculum Vitae with instant direct download trigger.

---

## 🚀 How to Run
Open `index.html` in your web browser. Click on the "Projects" nav link to view project cards, or click the "Resume" button to preview and download the CV document.
