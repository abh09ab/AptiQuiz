## 🚀 How to Deploy

### Option A: Deploy via GitHub Pages (Zero Config)
1. Push your repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Branch**, select `main` and root folder `/` (or `/Codomax_Portfolio/Module_6_Final_Portfolio/`).
4. Click **Save**. Your site will be live at `https://abh09ab.github.io/portfolio/` in ~60 seconds!

### Option B: Deploy via Vercel (Recommended)
1. Install Vercel CLI or link repository at [vercel.com](https://vercel.com).
2. Run `vercel` in terminal or import your GitHub repository.
3. Your portfolio will deploy with a free `.vercel.app` domain!
