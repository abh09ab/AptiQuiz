## 📌 Module Overview
Module 1 establishes the structural foundation of the developer portfolio using semantic HTML5 and modern CSS fundamentals.

### Key Implementations:
1. **Semantic HTML5 Architecture:**
   - `<header>` with responsive navigation bar and brand identity.
   - `<main>` containing structured sections: `#home`, `#about`, `#skills`, and `#contact`.
   - `<footer>` with copyright and essential outbound links.
2. **Hero / Home Section:**
   - Personalized greeting, headline, B.Tech credentials, and call-to-action buttons.
   - Profile avatar showcase with status indicator.
3. **About Me Section:**
   - Developer bio highlighting technical focus, degree details, and contact points.
4. **Skills Section:**
   - Categorized tech stack (Frontend, Backend & Database, Tools & Workflow) using modular pill tags.
5. **Contact Section:**
   - Clean contact form with input fields for name, email, and message.
6. **Basic CSS Design System:**
   - CSS custom properties (variables) for theme consistency.
   - Clean dark-mode palette (`#090d16` background, indigo/cyan accent gradients).
