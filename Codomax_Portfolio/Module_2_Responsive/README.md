## 📌 Module Overview
Module 2 elevates the raw structure from Module 1 into a fully responsive, multi-device layout engineered using modern CSS Grid and Flexbox methodologies.

### Key Implementations:
1. **Multi-Device Responsive Breakpoints:**
   - **Desktop (>1024px):** Multi-column grid layouts with fixed visual panels.
   - **Tablet (768px - 1024px):** Dynamic flex column reorientation with preserved card proportions.
   - **Mobile (<768px):** Single-column stacked layouts, fluid touch targets, full-width call-to-actions, and adaptive typography.
2. **Modern CSS Grid & Flexbox:**
   - Sticky glassmorphism header with aligned navigation items.
   - 2-column About section with dynamic engineering metrics grid.
   - Responsive multi-card tech stack grid.
   - 2-column contact wrapper splitting direct email links and structured form inputs.
3. **Design System & Typography:**
   - Imported Google Fonts (`Outfit` for high-impact headings, `Plus Jakarta Sans` for body legibility).
   - FontAwesome 6 icon set integrated across all nav items, cards, and buttons.
   - Radial glow ambient lighting effects and HSL gradient accents.

## 🚀 How to Run
Open `index.html` in your browser. Resize the window or use Developer Tools Device Mode (Ctrl+Shift+M) to test mobile, tablet, and desktop viewports.
