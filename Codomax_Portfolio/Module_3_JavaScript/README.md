## 📌 Module Overview
Module 3 breathes interactive life into the portfolio website through vanilla ES6+ JavaScript, handling user state, DOM manipulation, responsive drawer behavior, and client-side form validation.

### Key Implementations:
1. **Dark / Light Mode Theme Engine:**
   - Persistent theme state via `localStorage.getItem("portfolio_theme")`.
   - Dynamic `data-theme="light"` and `data-theme="dark"` attribute injection with smooth CSS color transitions.
   - Animated SVG/icon state change between Sun and Moon.
2. **Mobile Hamburger Menu & Drawer:**
   - Smooth slide-out mobile navigation drawer with backdrop blur overlay.
   - Automatic drawer closure on backdrop click or navigation link selection.
3. **Scroll Reveal & IntersectionObserver Animations:**
   - Observes sections and triggers smooth slide-up reveal animations as the user scrolls.
   - Dynamic active navigation link highlighting tracking current viewport section.
4. **Animated Stat Counters:**
   - Easing number count-up animation for metrics upon entering the viewport.
5. **Robust Contact Form Validation:**
   - Custom client-side validation ensuring valid name length, email regex format, subject, and message length.
   - Real-time error state removal as the user types.
   - Visual success banner with automated form reset.

---

## 🚀 How to Run
Open `index.html` in your web browser. Click the theme toggle icon in the top right to switch between Dark and Light mode, resize the window to mobile view to test the drawer, and test form validation by submitting the contact form.
